# 의료 어휘집 — Kiwi 경계 보호 + 후보 타입 (2026-09-21)

**온톨로지가 아니다.** 그래프도 관계도 없다. 표면형·타입·출처 세 칸이다. 부위 온톨로지(`data/ontology/`)의
"병명 노드를 두지 않는다"는 선(`docs/ai-design.md` §1 ①)은 그대로다. 이 파일들은 형태소 분석기가
`위산약`을 `위산/약`으로 쪼개지 않게 하고, 후보 span에 타입(소견/약/검사)을 붙이는 데만 쓴다.
설계: `docs/candidate-selection.md` §3.4.

| 파일 | type 값 | 예 |
|---|---|---|
| `findings.csv` | `finding` | 위염, 역류성 식도염, 안구건조증 |
| `medications.csv` | `medication` | 위산약, 소염제, 프로톤펌프억제제 |
| `tests.csv` | `test` / `procedure` | 혈액검사, 엑스레이 / 스케일링, 물리치료 |

컬럼 `surface,type,source,note`. `source` 필수(로더 검증). 표면형은 환자가 쓰는 형을 그대로 둔다
(`피검사`와 `혈액검사` 둘 다). 띄어쓰기 변형은 한 줄만 두면 된다 — 매칭이 공백을 무시한다.

넣지 않는 것: 일반어와 충돌하는 짧은 말(`약`, `물`, `열`), AI가 추론해 붙일 병명. 여기 있는 병명은
환자가 옮긴 의사의 말을 **알아보기** 위한 것이고, 카드에 병명을 **만들어 넣는** 데 쓰지 않는다.
