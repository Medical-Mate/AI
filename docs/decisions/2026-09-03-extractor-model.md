# [결정] 진료 전 카드 챗봇 Extractor 모델 선정

- 날짜: 2026-09-03
- 작성: AI 담당
- 상태: **결정** — GPT-5.6 Terra 1차 채택, Claude Sonnet 5 동등 대안
- 관련: `evals/RESULTS.md`, `evals/precondition-sheet.md`, `evals/cases.jsonl`

---

## 한 줄 요약

환자 발화를 SOCRATES 8축 JSON으로 추출하는 Extractor 역할에 대해 5개 모델을 같은 프롬프트·같은 케이스로 비교했다. **GPT-5.6 Terra와 Claude Sonnet 5가 51/51로 동률**이었고, Terra가 출력이 짧아 비용이 약 45% 낮아 1차로 채택한다. 안전 조건(병명 창작·숫자 창작·근거 변조)은 다섯 모델 모두 0건이었다.

---

## 무엇을 평가했나

진료 전 카드 챗봇의 LLM 역할은 하나다. **환자의 한 발화에서 어느 축에 무엇이 말해졌는지 뽑아 JSON으로 낸다.** 질문 문장은 템플릿이 만들고 대화 흐름은 결정론 엔진이 관리하므로, LLM 품질은 이 추출 단계에서 결정된다.

입력: 환자 발화 한 문장 + 지금 물은 축
출력: 축별 `status`(filled/unknown/skipped/ambiguous) · `value`(환자 표현) · `evidence`(발화 원문 인용) · `notes` · `wants_to_stop`

---

## 평가 기준

제품 원칙(`docs/ai-design.md` §1·§5)에서 Extractor를 구속하는 규칙 9개를 뽑고, 각각을 코드로 채점 가능한 검사로 바꿨다. **LLM judge는 쓰지 않았다.** 채점이 재현되고 비용이 0이며, 판정 분산이 없다.

| 검사 | 무엇을 보나 | 왜 중요한가 |
|---|---|---|
| D1·D2 | JSON 파싱, 스키마 준수, 여분 필드 없음 | 파싱 실패는 그 턴이 버려진다 |
| D4 | `evidence`가 발화의 부분 문자열인가 | **근거 변조 방지.** 한 글자라도 고치면 실패 |
| D5 | 출력의 숫자가 전부 발화에 있는가 | **숫자 창작 방지.** "타이레놀"에서 "500mg"를 만들면 실패 |
| D6 | 병명 사전(50개) 단어가 출력에 있으면 발화에도 있는가 | **진단 창작 방지.** 환자가 옮긴 병명은 통과, AI가 붙인 병명은 실패 |
| D7·D8 | 갱신한 축 집합과 상태가 기대와 일치하는가 | 축 배정 정확도 |
| D9·D10 | 종료 의사 판단, 첫 턴 주 호소 | 대화 제어 |
| VC·VN | 헤지("가끔")가 value에 남았는가 / 환자 추측 병명이 value에 안 들어갔는가 | 원문 충실성 |

D4·D5·D6은 **안전 조건**이다. 통과율이 아니라 위반 건수로 보고, 한 번이라도 나면 그 건은 카드에 창작된 내용이 의사에게 간다는 뜻이다.

결정론 채점이 못 보는 것(value의 의미 변형, notes에 해석이 섞이는 것)은 32개 출력을 전부 사람이 읽어 확인했다.

## 실험 설계

| 항목 | 값 |
|---|---|
| 케이스 | 32개 (정상 11 · 경계 4 · 무응답 3 · 상태 구분 6 · 진단 유도 4 · 숫자 유도 2 · 문서 병명 2) |
| 반복 | 안전 케이스 3회, 무응답 2회, 나머지 1회 → **모델당 51회 호출** |
| 프롬프트 | 전 모델 동일 (`extract-v2`). 텍스트 JSON 응답 후 파싱. 스키마 강제(structured output)는 어느 쪽에도 쓰지 않음 |
| 판정 규칙 | 51회 중 **3회 미만 차이는 "차이 없음"** |
| 비교 모델 | 중간 등급: GPT-5.6 Terra · Claude Sonnet 5 · Gemini 3.5 Flash / 싼 등급: Claude Haiku 4.5 · GPT-5.6 Luna |

이 규모는 "고르기"용이다. 두 모델 차이를 통계적으로 입증하는 규모가 아니다. 그래서 동률은 동률로 두고 비용으로 갈랐다.

## 결과

| 모델 | 등급 | 통과 | 안전 위반 | 출력 토큰 | 비용 (51회) |
|---|---|---|---|---|---|
| **GPT-5.6 Terra** | 중간 | **51/51** | 0 | 2,917 | **$0.14** |
| **Claude Sonnet 5** | 중간 | **51/51** | 0 | 9,213 | $0.26 |
| Claude Haiku 4.5 | 싼 | 49/51 | 0 | 6,208 | $0.11 |
| GPT-5.6 Luna | 싼 | 49/51 | 0 | 6,206 | $0.02 |
| Gemini 3.5 Flash | 중간 | 46/51 | 0 | 14,169 | $0.21 |

전체 실험 지출: 약 **$0.85** (프롬프트 v1 실행과 Gemini 재실행 포함).

### 점수 밖에서 본 것

- **Terra · Sonnet · Luna는 value를 발화에서 그대로 잘라 쓴다.** 이 제품은 "환자 말을 그대로 옮기는 것"이 핵심이라 이 성향이 곧 품질이다.
- **Haiku는 가볍게 다듬고, notes에 해석을 쓴다.** "환자가 진료를 서두르려는 태도 보임" 같은 문장. 카드에 AI의 판단이 섞이는 방향이라 감점.
- **Gemini는 어머니의 무릎을 환자 부위로 기록했다** (2회 모두). 결정론 검사에는 안 걸리지만 "타인 기록을 받지 않는다"는 원칙에 정면으로 걸린다. 5개 중 유일.
- Sonnet은 내용은 같고 문장을 덜 자른다. 출력 토큰이 Terra의 3배이고, 그게 비용 차이다.

### 실패 내역

| 모델 | 케이스 | 무엇 |
|---|---|---|
| Haiku | "거기가 또 아파요" | 지시어 모호 표시(ambiguous) 누락 |
| Haiku | 무관한 잡담 (2회 중 1회) | 물은 축에 값 아닌 상태 생성 |
| Luna | "잘 모르겠는데 한 3일쯤" | unknown 처리 — 값이 있는데 버림 |
| Luna | "그건 말하고 싶지 않아요" | 항목 거부를 종료 의사로 오독 |
| Gemini | "우리 엄마도 무릎이 안 좋은데" (2/2) | 타인 증상을 site로 기록 |
| Gemini | "가끔 찌릿해요" | "가끔"을 다른 축으로 분리 → 헤지 탈락 |
| Gemini | "거기가 또 아파요" | onset="또" 생성 |

## 추론 속도

**측정하지 않았다.** 이번 러너는 호출별 응답 시간을 기록하지 않았고 Langfuse 트레이싱도 아직 붙이지 않았다. 체감상 다섯 모델 모두 51회가 수 분 안에 끝났고 Gemini는 사고 토큰 때문에 가장 느렸지만, 수치는 없다. 다음 실행부터 호출별 latency를 기록하고 Langfuse에 남긴다.

## 결정

1. **Extractor 기본 모델: GPT-5.6 Terra.** 품질 동률에 비용 우위.
2. **Claude Sonnet 5는 동등 대안.** 어댑터를 그대로 유지하고, 프롬프트를 바꿀 때마다 둘을 같이 돌려 비교한다.
3. **GPT-5.6 Luna는 개발·폴백용.** 실패 2건이 모두 "값이 있는데 버리는" 쪽이라 카드에 창작이 들어가는 방향은 아니다.
4. **Gemini 3.5 Flash는 이 태스크에서 제외.** 타인 증상 혼입과 헤지 분리가 제품 원칙과 충돌한다.

---

## 실험 중 배운 것 (다음 eval에 반영)

- **1차 실행(프롬프트 v1)에서 Luna 실패 15건 중 11건이 한 원인**이었다. "아파요"를 느낌(character) 축으로 뽑은 것. 프롬프트가 이걸 정하지 않은 명세 공백이었고, v2에 규칙을 넣고 전 모델을 다시 돌렸다. 그래서 v2 점수는 케이스에 맞춰 조정된 것이라 낙관적일 수 있다.
- **v1에서 Haiku가 evidence를 한 글자 바꿔 쓴 위반 1건**이 있었다("속도"→"속도도"). v2에서 재현되지 않았다. 1회 관측이라 결론은 못 내리지만, 근거 인용을 글자 그대로 복사하는 능력이 실제로 갈리는 지점임은 확인됐다.
- **Gemini는 사고 토큰이 출력 한도에 포함된다.** 한도 1024로 두면 JSON이 40토큰쯤에서 잘리고 사고 텍스트가 새어 나온다. 8192로 올려야 한다. 이건 모델 오류가 아니라 어댑터 오류로 판정하고 해당 11건만 재호출했다.
- 제 케이스 기대값 5개가 틀려서 정당한 응답을 실패 처리했다(물은 축을 skipped로 닫는 것, 증상 없는 질문에 주 호소가 없는 것 등). 저장된 응답으로 재채점해 재호출 없이 고쳤다.

## 한계

- 케이스 32개, 반복 최대 3회. 통계적 입증이 아니라 선택 근거다.
- 멀티턴 문맥, 응급 red flag, 실제 환자 발화의 오타·방언은 포함되지 않았다.
- 추론 속도 미측정.
- 채점은 결정론만이고, 의미 충실성은 사람 검수다.
