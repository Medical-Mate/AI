# 신체 부위 → 진료과 안내 근거 조사

조사일: 2026-09-04 (모든 확인 날짜 동일). WebSearch + WebFetch로 페이지를 직접 열어 문구를 확인했다.
WebFetch가 페이지를 요약해 돌려주는 경우가 있어, "원문 인용"으로 표시한 문구는 도구가 한국어 원문으로 돌려준 것만 적었다. 영문 요약으로만 확인된 것은 "(요약 확인)"으로 표시했다.

목적: 진단·감별 자료가 아닌 "이 부위/증상은 보통 어느 진료과에서 진료한다" 안내 근거. 진료과 "안내"는 결정 대기 이슈이므로 이 문서는 착수 근거가 아니라 자료 목록이다.

### 찾았으나 쓸 수 없는/못 찾은 출처
- 심평원(hira.or.kr) "진료과목 설명" 페이지: **못 찾음**. 심평원 사이트는 병원·약국 찾기, 병원평가, 진료과목 코드(법령 별표)만 있고 "이 증상은 어느 과" 식 국민용 설명 페이지는 없다.
- 대한의학회(kams.or.kr) 전문과목 소개: 검색에 잡힌 페이지는 "명예의 전당" 인물 소개였다. 전문과목 안내 페이지 **못 찾음**.
- 대한의사협회, 대한신경과학회, 대한정형외과학회, 대한피부과학회(derma.or.kr), 대한이비인후과학회: 국민용 "어떤 부위/증상을 진료하나" 안내 페이지를 검색으로 확인 못 함. 피부과의사회(akd.or.kr)는 "피부과 전문의란" 페이지가 있으나 자격 설명 위주. → 학회 계열은 이번 조사에서 **직접 명시 근거 없음**.
- 국가건강정보포털 두통·흉통 페이지: 진료과 안내 문구 **없음** (증상·원인·치료·병원 방문 시점만 다룸). 도구 확인 결과 "진료과/어느 과/신경과" 언급 없음.

## 5. 정리
- 공공 출처(KDCA·심평원·E-GEN·복지부) 중 "부위 → 진료과"를 직접 말하는 페이지는 **없다**. 공공 출처가 주는 것은 (a) 경증은 동네 병·의원 먼저(복지부, 제1유형), (b) 흉통 시 119/응급실(E-GEN, KDCA)까지다.
- 부위 → 진료과 직접 명시는 전부 서울대학교병원 N의학정보의 "진료과" 필드에서 나왔고, 이는 저작권 보유(ALL RIGHTS RESERVED) 콘텐츠다.
- SNUH 진료과 필드는 요청안보다 넓다(예: 두통에 신경외과·가정의학과, 인두염에 호흡기내과, 발진은 내과만). 요청안의 괄호 과목을 임의로 좁혀 쓰면 "출처와 일치" 보증이 깨진다.
