# 결정: 브리핑 카드의 진료과 안내 — 부위 기반, 우리 콘텐츠

날짜 2026-09-04. 결정자: AI 담당(팀 위임). 상태: **결정됨, 의료인 자문 후 재검토**.

## 결정

브리핑 카드에 **진료과 안내**를 넣는다. 단, 다음 규칙을 코드 구조로 강제한다.

1. **부위 노드의 속성이다.** 진료과는 온톨로지 노드(표면 구역 우선, 없으면 앵커)에 붙은 값이다.
   증상 8축(character, severity 등)은 **절대 참조하지 않는다.** 증상을 보고 과를 고르면 감별이다
   (`docs/ai-design.md` §2). 부위만 보면 안내다.
2. **애매하면 내과가 기본값, 나머지는 괄호에 전부.** 코드가 고르지 않는다. 노드에 적힌 것을 그대로 낸다.
   한국 1차 의료에서 일상 증상은 의원(내과·가정의학과)에서 먼저 진료한다는 현실을 따른다
   (복지부 2019-09-04 보도자료 "경증환자는 동네 병·의원을", 공공누리 1유형).
3. **응급 안내가 먼저다.** 가슴 등 응급 자리인 부위는 진료과보다 응급 문구를 위에 둔다.
4. **안내 어투, 추천 아님.** 문구는 "보통 ○○에서 진료합니다. 접수 시 확인해 주세요".
   필드명은 `department_guidance`. `recommended_department` 같은 이름을 쓰지 않는다.
5. **우리 콘텐츠다. 인용이 아니다.** 아래 표는 팀이 정한 값이고 출처 표기는
   "팀 결정 2026-09-04, 의료인 자문 확인 전". "출처와 일치" 보증 대상에서 제외한다.

## 왜 인용이 아닌가

인용 가능한 근거를 찾아봤다(부록 `2026-09-04-department-guidance-sources.md`).

- 공공 출처(국가건강정보포털·심평원·응급의료포털·복지부)에는 "부위 → 진료과" 문구가 **없다.**
- 직접 명시한 출처는 서울대병원 N의학정보의 "진료과" 필드뿐이고 저작권 보유(ALL RIGHTS RESERVED)다.
  서울아산병원도 같고 재가공 금지다. 학회·협회 국민용 안내 페이지는 찾지 못했다.

그래서 인용으로는 갈 수 없다. 서울대병원 필드는 **우리 표가 방향이 맞는지 대조**하는 데만 썼다.

## 매핑 (v1)

규칙: 구역에 값이 있으면 구역, 없으면 앵커. 괄호는 병기이며 순서에 의미 없다.

| 앵커 | 안내 | 비고 |
|---|---|---|

| 가슴 | 내과 (심장내과·호흡기내과) | **응급 안내 우선** |
| 배 | 내과 (소화기내과) | |
| 허리 | 정형외과 (신경외과) | |
| 어깨 · 팔꿈치 · 손목·손 · 엉덩이 · 무릎 · 발목·발 | 정형외과 | |
| 전신 | 내과 (가정의학과) | 발열·오한·피로. 사이드 탭 |
| 피부 | 피부과 (내과) | **앵커 신설 필요** (온톨로지 트랙). 사이드 탭 |

### 구역 (앵커와 다르거나 더 구체적인 것만)

| 앵커 | 구역 | 안내 |
|---|---|---|
| 머리 | 눈 | 안과 |
| 머리 | 귀 / 코 | 이비인후과 |
| 머리 | 입 | 이비인후과 (치과) |
| 머리 | 머리(두피·이마) | 신경과 (가정의학과) |
| 목 | 목 안(목구멍) | 이비인후과 (내과) |
| 목 | 목 뒤·옆 | 정형외과 (신경외과) |
| 가슴 | 가슴 가운데 | 내과 (심장내과·호흡기내과) — 응급 우선 |
| 가슴 | 가슴 옆(갈비) | 내과 (정형외과) |
| 배 | 윗배(명치) | 내과 (소화기내과) |
| 배 | 아랫배 | 내과 (소화기내과·산부인과·비뇨의학과) |

나머지 구역은 앵커 값을 쓴다. 아랫배의 산부인과는 성별을 참조하지 않고 항상 병기한다(조건 분기도 감별이다).

## 리스크와 완화

이 기능은 팀이 감수하기로 한 리스크가 있다.

| 리스크 | 완화 |
|---|---|
| 잘못된 과로 안내해 진료가 늦어진다 | 애매한 부위는 내과 기본값 + 전부 병기. "접수 시 확인" 문구. 응급 우선 |
| 안내가 "추천·진단"으로 읽힌다 | 안내 어투 고정, 필드명·문구에 추천 어휘 금지. 증상 축 미참조를 코드로 보장 |
| 근거 없는 콘텐츠라는 지적 | 출처 표기를 "팀 결정, 자문 전"으로 정직하게. 의료인 자문 회신 후 재검토 항목으로 등록 |
| 인체도 부위가 바뀌면 표가 어긋난다 | 값은 `manual/nodes.csv`에만 둔다. 노드가 바뀌면 같은 파일에서 고친다 |

## 구현 위치

- 데이터: 온톨로지 트랙 `data/ontology/manual/nodes.csv`에 `departments` 컬럼(복수, `;` 구분)과 앵커 「피부」 추가.
  로더는 값을 그대로 노출만 한다. 선택·정렬 로직 없음
- 카드: `schema/export.py`에 `department_guidance: {primary, also, note}` 자리. 백엔드 최종 필드명은 백엔드가 정한다
- 응급: 가슴 앵커는 기존 응급 안내 예외 경로가 먼저 걸린다

## 재검토 조건

- 의료인 자문 회신 → 표 전체 검토
- 서울대병원 등 콘텐츠 허락 또는 공공 출처 발견 → 인용 방식으로 전환, "출처와 일치" 보증 대상에 포함
- 디자이너 인체도 확정 → 앵커·구역 이름 맞추기
