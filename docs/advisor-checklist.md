# 의료인 확인서 (초안) — 진료 메이트 AI 문진·안내 설계

작성 2026-09-04, 2절 개정 2026-09-07. 회신 방식: 각 항목에 **맞음 / 수정 / 삭제** 중 하나를 표시하고, 수정·삭제는 한 줄 이유를 적어 주세요.
열린 질문이 아니라 확인입니다. 설계와 표는 저희가 만들었고, 임상적으로 틀린 것이 없는지만 봐 주시면 됩니다.

## 0. 이 시스템이 하지 않는 것 (전제)

- 진단·감별을 하지 않습니다. 병명은 환자가 "의사가 이렇게 말했다"고 옮긴 것만 기록합니다.
- 설명문을 생성하지 않습니다. 공공저작물을 출처 표시해 인용만 합니다(라이선스 확인 중).
- 증상을 보고 진료과를 고르지 않습니다. 부위에 붙은 안내만 보여 줍니다.
- 예외: 응급 안내는 합니다(문구는 아래 §4).

## 1. 진료 전 문진 — 8축과 질문 문구

| # | 축 | 질문 | 확인 |
|---|---|---|---|
| 1-1 | 부위 | 불편한 곳이 정확히 어디쯤인가요? | ☐ 맞음 ☐ 수정 ☐ 삭제 |
| 1-2 | 시작 | 언제부터 그러셨어요? 갑자기 시작됐나요, 서서히 시작됐나요? | ☐ |
| 1-3 | 느낌 | 어떤 느낌인가요? 예를 들면 욱신거리는지, 찌르는 것 같은지, 조이는 것 같은지요. | ☐ |
| 1-4 | 심각도 | 가장 심할 때를 10점이라고 하면 지금은 몇 점 정도인가요? | ☐ |
| 1-5 | 경과 | 처음보다 지금은 어떤가요? 심해졌는지, 비슷한지, 나아졌는지요. | ☐ |
| 1-6 | 악화·완화 | 어떤 때 더 심해지고, 어떤 때 좀 괜찮아지나요? | ☐ |
| 1-7 | 퍼짐 | 그 불편함이 다른 곳으로 퍼지기도 하나요? | ☐ |
| 1-8 | 동반 증상 | 같이 나타나는 다른 증상이 있나요? | ☐ |
| 1-9 | 마무리 | 마지막으로, 의사 선생님께 꼭 전하고 싶은 말이 더 있으세요? | ☐ |

- 1-10 순서(부위 → 시작 → 느낌 → 심각도 → 경과 → 악화완화 → 퍼짐 → 동반)가 적절한가 ☐
- 1-11 빠진 축이 있는가 (예: 이전 삽화 "예전에도 이랬는가") — 있다면 무엇 ☐
- 1-12 답을 확정할 수 없을 때 확인 질문을 **한 번만** 하고 넘어가는 규칙이 적절한가 ☐

## 2. 진료 후 기록 — 메모를 네 묶음으로 나누기 (2026-09-07 설계 변경)

진료 후에는 질문하지 않습니다. 환자가 진료실에서 들은 말을 **자유 메모**로 적으면, 시스템이 문장 단위로 아래 네 묶음에 나눠 보여 줍니다.
문장은 원문 그대로 옮기고, 요약·보완·해석을 하지 않습니다. 어느 묶음에도 맞지 않는 문장(잡담·행정)은 "분류 안 됨"에 둡니다.
환자가 묶음을 손으로 옮길 수 있습니다.

| # | 묶음 | 정의 | 예시(환자 메모 원문) | 확인 |
|---|---|---|---|---|
| 2-1 | 들은 소견 | 의사가 몸 상태에 대해 한 말. 병명·상태·안심·부정 소견 포함 | "위염 초기라고 하셨어요" · "뼈는 괜찮대요" · "중이염은 아니고 귀지 때문이라고" | ☐ 맞음 ☐ 수정 ☐ 삭제 |
| 2-2 | 검사 | 받은 검사·영상, 결과 안내 방식, 검사 예약 | "피검사 했어요" · "결과는 다음에 알려준대요" · "10월 2일 시야검사 예약함" | ☐ |
| 2-3 | 약·지시 | 약·처방·주사·처치·복용법, 생활 지시와 금지 | "약은 2주분" · "주사 한 대 맞았어요" · "반깁스 4주" · "계단은 피하라고" · "약은 안 주셨어요" | ☐ |
| 2-4 | 다시 오기 | 다시 오라는 시점 또는 조건. 날짜는 진료일 기준으로 계산해 달력에 넣습니다 | "2주 뒤에 오라고" · "다음 달 15일에" · "안 좋아지면 바로 오래요" | ☐ |

- 2-5 한 문장에 둘이 섞이면 **다시 오기 → 약·지시 → 검사 → 소견** 순으로 먼저 걸리는 묶음 하나에 둡니다(예: "피검사 다시 하고 결과 보자고" → 다시 오기). 이 우선순위가 적절한가 ☐
- 2-6 검사 예약 날짜("10월 2일 시야검사")는 검사 묶음에 두고 재방문 날짜로 잡지 않습니다. 치료 예약("다음 주 목요일 충치 치료 시작")은 다시 오기입니다 ☐
- 2-7 "통증 심하면 응급실 가라고"처럼 조건부 대처 지시는 약·지시에 둡니다(다시 오기 아님) ☐
- 2-8 "약 먹을 정도는 아니라고", "수술은 필요 없다고"처럼 약·수술 여부 판단: 약 언급은 약·지시, 수술 불필요는 소견 ☐
- 2-9 환자가 옮긴 병명을 그대로 기록하는 것(예: "반월판이 조금 찢어졌다고")이 위험하지 않은가 ☐
- 2-10 약 용법은 환자가 적은 것만 기록하고, 시스템이 일반 용법을 채우지 않는 규칙 ☐
- 2-11 빠진 묶음이 있는가 (예: 진단서·소견서 수령 여부, 못 물어본 것) ☐
- 2-12 네 묶음 이름(들은 소견 / 검사 / 약·지시 / 다시 오기)이 환자에게 오해 없이 읽히는가 ☐

## 3. 부위 → 진료과 안내 표

규칙: 구역에 값이 있으면 구역, 없으면 앵커. 애매하면 내과 기본값 + 나머지 병기. 증상은 보지 않습니다.
문구: "보통 ○○에서 진료합니다. 접수 시 확인해 주세요."

| # | 부위 | 안내 | 확인 |
|---|---|---|---|
| 3-1 | 머리 전체·이마 | 신경과 / 가정의학과 | ☐ |
| 3-2 | 눈 | 안과 | ☐ |
| 3-3 | 귀 · 코 · 입 | 이비인후과 | ☐ |
| 3-4 | 목 안(목구멍) | 이비인후과 / 내과 | ☐ |
| 3-5 | 목 뒤·옆 | 정형외과 / 신경외과 | ☐ |
| 3-6 | 가슴 가운데 | 내과 / 심장내과 / 호흡기내과 (응급 안내 우선) | ☐ |
| 3-7 | 가슴 옆(갈비) | 내과 / 정형외과 | ☐ |
| 3-8 | 윗배(명치) | 내과 / 소화기내과 | ☐ |
| 3-9 | 아랫배 | 내과 / 소화기내과 / 산부인과 / 비뇨의학과 | ☐ |
| 3-10 | 팔 (어깨·위팔·팔꿈치·아래팔·손목·손) | 정형외과 | ☐ |
| 3-11 | 다리 (허벅지·무릎·종아리·발목·발) | 정형외과 | ☐ |
| 3-12 | 허리 가운데 · 엉덩이 | 정형외과 / 신경외과 | ☐ |
| 3-13 | 허리 옆 | 내과 / 비뇨의학과 / 정형외과 | ☐ |
| 3-14 | 전신 (발열·오한·피로) | 내과 / 가정의학과 | ☐ |
| 3-15 | 피부 | 피부과 / 내과 | ☐ |

- 3-16 "애매하면 내과 기본값" 원칙이 1차 의료 현실에 맞는가 ☐
- 3-17 아랫배에 성별 무관하게 산부인과를 병기하는 것 ☐

## 4. 응급 안내

- 4-1 응급 안내를 띄울 표현·부위(예: 가슴 통증 + 식은땀·호흡곤란, 자해 표현)의 목록을 만들어 주실 수 있는지, 또는 저희 초안을 검토해 주실지 ☐
- 4-2 문구 초안: "지금 증상이 갑자기 심해졌거나 숨이 차면 119에 연락하거나 가까운 응급실로 가세요." ☐

## 5. 용어 병기 (온톨로지)

환자가 옮긴 의사의 말에 부위를 붙여 줍니다. 예: "앞십자인대" → 앞십자인대(전방십자인대)(인대) · 부위: 다리.
- 5-1 부위를 붙이는 것(설명 없이 위치만)이 오해를 만들지 않는가 ☐
- 5-2 구조 이름 한국어 표기 40개 목록(별첨) 검토 ☐
