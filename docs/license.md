# 데이터·모델 라이선스

AI 저장소가 가져다 쓰는 외부 자산의 라이선스 조건입니다.
**새 데이터·모델을 추가할 때 이 문서에 한 줄 추가하고 PR 체크리스트에 표시합니다.**

대회 규정은 확인됐습니다 — *"오픈소스, 외부 API, 생성형 AI도 **저작권과 라이선스**,
소속 기관의 관련 규정을 준수하면 활용할 수 있다."*
→ 규정상 허용이고, **문제는 각 자산의 조건 준수**입니다.

**덩어리로 걱정하지 않습니다. 위험도가 다르고 실제로 걸리는 건 하나입니다.**

---

## ★ 유일하게 실제로 걸리는 것 — 국가건강정보포털

**직접 페이지 조회 결과 (2026-09-01):**

> **공공누리 제4유형** — **비상업적 이용만 가능** + **변형 등 2차적 저작물 작성 금지**
> (별도 이용허락 절차는 불필요)

### 두 조건을 따로 봐야 한다

| 조건 | 우리 설계에 걸리나 |
|---|---|
| **변경 금지** | **안 걸린다.** 이미 "설명문을 생성하지 않고 인용한다"로 확정했다(`ai-design.md` §1-③). 원문 그대로 쓰면 된다 |
| **비상업적 이용만** | **여기가 문제다.** 공모전 출품이 상업적인가? **상금 1,000만원이 걸려 있다** |

### 근거가 충돌한다 — 단정하지 않는다

- **직접 조회(WebFetch)**: **제4유형**
- **검색 요약**: *"제1유형 출처표시 조건"*, *"텍스트 데이터는 출처표시 조건으로 자유이용 가능"*
  단 *"사진·이미지·일러스트·동영상 등 일부는 저작권 전부를 갖고 있지 않아 별도 허락 필요"*

→ **콘텐츠 종류·페이지 단위로 유형이 다를 가능성이 있다.**
텍스트는 1유형, 이미지는 4유형일 수도 있다. **내가 확정할 수 없다.**

### 할 일 — **질병관리청에 직접 문의. 며칠 걸리므로 지금 보낼 것**

물을 것 세 개:
1. **건강정보 텍스트 콘텐츠의 공공누리 유형**이 정확히 몇 유형인가
2. **공모전 출품(상금 있음)이 「비상업적 이용」에 해당**하는가
3. **Open API**로 받는 데이터의 이용 조건이 웹 콘텐츠와 같은가

### 대안 — 문의 답이 막히면

| 순위 | 대안 | 장점 | 단점 |
|---|---|---|---|
| 1 | **문의 후 그대로 사용** | 한국어 원문 · 공공기관 신뢰도 | 답 기다려야 함 |
| 2 | **UBERON의 `def:` 필드를 번역** — `nodes.csv`에 이미 뽑혀 있다 | 라이선스가 깨끗할 가능성 높음(CC-BY 계열) | **번역은 생성에 가깝다.** 오역 위험 → 개정 6의 순환 문제로 되돌아간다. **자문 감수 필수** |
| 3 | **설명문 없이 용어 병기만** — "전방십자인대(ACL) · 무릎의 인대" | **라이선스 위험 0** | 제품이 얇아진다 |

**2번은 차선이다.** 공공기관 한국어 원문보다 신뢰도가 낮고, "우리가 설명문을 만들지 않는다"는
원칙이 흔들린다. 3번은 안전하지만 값이 준다.

## 위험이 낮은 것들 — 여기까지 걱정하지 않아도 된다

| 자산 | 상태 | 왜 낮은가 |
|---|---|---|
| **ML Kit 한국어 OCR** | 약관 확인 필요 | Google SDK를 앱에 넣는 **정상 용법**이다. 그리고 **대안이 있다** — PaddleOCR·Tesseract 둘 다 Apache 2.0 |
| **Synthea** | 확인 필요 | MITRE 공개 **합성 데이터**. 실제 환자 데이터가 아니다 |
| **UBERON** | CC-BY 추정, 미확인 | OBO Foundry 계열. 그리고 **대안이 있다** — 40개 규모면 직접 구축 가능 |
| **SNOMED CT** | 회원제·라이선스 있음 | **우리는 ID만 참조하고 콘텐츠를 쓰지 않는다**(`nodes.csv`의 `sctid` 컬럼). 위험이 크게 낮아진다 |
| **KOSTOM / KR CDI** | 확인 필요 | 보건복지부 고시 자료. 공공저작물 성격 |

## 지키면 대부분 막히는 방어 세 개

1. **출처를 제출물에 명시한다.** 대부분의 라이선스가 요구하는 게 출처표시다.
   그리고 이건 **심사에도 유리하다** — 선행 연구 명시 원칙과 같다
2. **변경하지 않고 인용한다.** 이미 그렇게 설계했다. 공공누리 3·4유형의 변경 금지에도 안 걸린다
3. **재배포하지 않는다.** 서비스 안에서 조회해 보여주는 것과 데이터셋을 배포하는 것은 다르다.
   **대부분의 라이선스가 재배포에 더 엄격하다** — 우리는 재배포하지 않는다

## 제출물에 쓸 문장

> 사용한 외부 자산과 라이선스를 전부 명시한다. 숨기지 않는다.
> 라이선스 조건 때문에 **하지 않기로 한 것**(설명문 변경·재배포)도 같이 적는다.
> **제약을 알고 설계했다는 게 심사에서 성숙도로 읽힌다.**
